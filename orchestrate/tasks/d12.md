# Mission: D12 wave 1 - the typed category structs

## Context (you start from zero context)

The repo is `crystal-cif-io`, a two-crate workspace. The
provisioned worktree is on branch `dict-items/d12`, based on
`dev-0.2`.

- `crystal-cif-fmt` (v0.1.0): the CIF 1.1/2.0 parser and IR.
  Types: `Tag`, `Value`, `DataBlock`, `DataItems`, `SaveFrame`,
  `DataBlockMember`, `SingleLineData`, `LoopColumn`, `Matrix`,
  `Numeric`, `CharString`. The term traits `CifTerm`,
  `SingleValueTerm`, `LoopValueTerm` live in
  `crystal_cif_fmt::term`.
- `crystal-cif-io` (v0.3.0, this wave's crate): `data_dict`
  (per-category term enums, closed-set value enums, the tag
  registry, under `data_dict/core_cif/<cat>/`) and `builder`
  (the five `bon` builders of D11: cell, cell-vectors,
  space_group, symop, chemical_formula, plus the formula_units
  cross-check).

This wave builds the typed document layer: one struct per
category. The doc struct is the builder's target shape (D12h).

Read first:

## The user's decisions (2026-10-17, binding)

- D12a (B): the category structs live in
  `data_dict/core_cif/<cat>/<cat>.rs`: `cell/cell.rs` (Cell),
  `space_group/space_group.rs` (SpaceGroup),
  `space_group_symop/space_group_symop.rs` (the Symop row),
  `atom_site/atom_site.rs` (the AtomSite row),
  `chemical_formula/chemical_formula.rs` (ChemicalFormula). The
  entry files keep the per-entry value types (CellAngle, the
  closed-set enums).
- D12b (A): every struct field is `Option<T>`. Reads are
  tolerant. `CoreCif::validate()` reports missing required
  items, using the required sets from dict-completeness section
  5.
- D12c (A): the group is always present. The fields are
  Option. The group is Default.
- D12d (A): a value class mismatch on a typed item fails
  `from_block`, listing every mismatch. Unknown tags go to
  `extra`.
- D12e (A): save frames go to `extra`, always, in wave 1.
- D12f (A): the five categories of wave 1.
- D12g (A): the block view is named `CoreCif`.
- D12h (A): the doc struct is the builder output. The builders'
  private structs are deleted. The `build()` calls return the
  doc structs.
- D13d (A): the `CifCategory` trait lives in
  `data_dict/core_cif/mod.rs`. `CoreCif` and `CifError` live
  in the crate root file `core_cif.rs`.
- The newtype convention: a plain item keeps the shared value
  type. No guardless wrapper. A clamped newtype carries a range
  guard. A closed-set item is an enum.

## The work, in order

1. `data_dict/core_cif/mod.rs`: the `CifCategory` trait
   (`to_members`, `from_members`) and the `CifError` enum
   (the `ValueClass`, `Shape`, `Missing` variants, Display in
   the "expected/actual" wording of typed-structs.md section 5).
2. The five category structs: public `Option<T>` fields,
   Default, `to_members` emits the set fields, `from_members`
   consumes only the own category's tags and returns the
   residue and the error list.
   - Field types: the existing entry value types and
     closed-set enums (CellAngle, AdpType, and the
     space_group closed-set fields). Numeric items are
     `Option<Numeric>`. Char items are `Option<CharString>`.
     Matrix items are `Option<Matrix>` with the
     `depends.json` dimension.
   - The row structs: `Symop` (space_group_symop), `AtomSite`
     (atom_site).
   - Register each struct in its category `mod.rs`.
3. `crystal_cif_io/src/core_cif.rs` (crate root; add
   `pub mod core_cif;` to `lib.rs`): `CoreCif` holds the four
   single groups, the two `Vec` row groups, and
   `extra: Vec<DataBlockMember>`. Provide `from_block`,
   `to_block`, `validate`.
   - `from_block`: walk the members. Each typed category's
     `from_members` consumes its tags. Save frame members and
     unknown tags go to `extra`, order kept. Collect every
     `CifError`, do not stop at the first.
   - `to_block`: emit the typed categories in a fixed order,
     then `extra`.
4. The builder re-point (D12h): `CellBuilder` and
   `CellVectorsBuilder` build `Cell`. `SpaceGroupBuilder`
   builds `SpaceGroup`. The symop builders build `Symop` rows.
   `ChemicalFormulaBuilder` builds `ChemicalFormula`. The
   formula_units cross-check consumes the doc structs. Delete
   the builder-private structs. This is a breaking change,
   pre-1.0. Note it in the CHANGELOG.
5. Tests, `crystal_cif_io/tests/typed_round_trip.rs` plus
   focused unit tests:
   - Round trip: `from_block`, `to_block`, `parse_cif` keeps
     every item. Run over the realistic structure fixture and
     a codebase CIF from
     `crystal_cif_fmt/tests/fixtures/`.
   - Residue: foreign tags and save frames survive in
     `extra`, unchanged.
   - `validate`: drop one required item, expect exactly one
     `Missing` that names it.
   - Builders: build, `to_block`, `parse_cif`, the `CoreCif`
     fields match the builder inputs.
6. `CHANGELOG.md`: an Unreleased entry for the new layer and
   the breaking builder change.

## Style and writing

- Repo code style: short factual doc comments. No comment that
  just states what the code says.
- Prose (commit messages, docs, CHANGELOG) follows the house
  rules: no contractions, no phrasal verbs, no semicolons, no
  perfect or progressive forms, sentences of 25 words or
  fewer, paragraphs of six sentences or fewer, active voice.
- Commit messages: imperative subject, body lines of 25 words
  or fewer.
- Do not touch `crystal_cif_fmt`.
- Do not start wave 2 (the other 57 categories).
