# Source of the real-data corpus

The files in `tests/real_data/iucr/` are the official CIF example
files published on the IUCr "CIF examples" page:

- index page: `https://journals.iucr.org/services/cif/examples.html`
- file URLs: `https://www.iucr.org/__data/iucr/ftp/pub/<name>.cif`
- fetched: 2026-10-12, via a headless browser (the IUCr sites are
  behind a Cloudflare challenge; a plain HTTP client gets the
  challenge page).

The files are (c) IUCr. They are used here as regression inputs
for the parser. The expected JSON files in
`tests/real_data/expected/` were generated by the crate's own
canonical encoder (`cargo run --example gt_generate --
--real-data`). They pin the parse output; they are a
self-consistency pin, not an independent ground truth.

| file | producer / shape |
|---|---|
| `example_single.cif` | SHELX single-structure report |
| `example_multiple.cif` | SHELX multiple structures |
| `example_VRF.cif` | report with a Validation Response Form |
| `example_squeeze.cif` | PLATON SQUEEZE disorder handling |
| `example_shelxl2013.cif` | SHELXL2013 output (the largest) |
| `example_jana.cif` | Jana output |
| `example_crystals.cif` | multi-crystal report |
| `example_olex2.cif` | Olex2 output |
| `rietresultsxmpl.cif` | Rietveld refinement results |
| `example_extra_table.cif` | report with an extra publ table |
| `example_publcif.cif` | publication-category example |
